Wie nah ist heute am Rekord?

wetterrekord.de ist eine Live-Karte der Wetterrekorde in Deutschland. An über 330 Wetterstationen vergleicht sie die heutigen Werte mit der eigenen Geschichte der Station — manche Messreihen reichen bis 1781 zurück.

Vier Stufen von Rekord

Jede Station wird mit ihrem Rekord für denselben Kalendertag, den Halbmonat, den Monat — und für alle Zeiten verglichen. Die Farbe zeigt, wie weit der heutige Tag reicht.

So funktioniert’s

Komplett auf Basis des Climate Data Center des Deutschen Wetterdienstes. Inspiriert von recordpy.fr.

1

Historie importieren

Beim ersten Start werden rund 340 Stationsarchive mit Tageswerten geladen und alle Rekorde in SQLite berechnet. Täglich um 04:30 neu berechnet.

2

Live-Werte abfragen

Alle 15 Minuten liefern die 10-Minuten-Daten des DWD das bisherige Maximum und Minimum des Tages — mit etwa 30 Minuten Verzögerung.

3

Vergleichen und zeigen

FastAPI liefert den Vergleich an eine Leaflet-Karte; für Link-Vorschauen wird serverseitig ein Bild des Tages erzeugt.

Selbst betreiben

Ein Container, ein Volume. Die Karte füllt sich, sobald der erste Import fertig ist.

Docker

git clone https://github.com/cygnusb/wetterrekord
cd wetterrekord
docker compose up -d

Danach http://localhost:8000 öffnen. Images: ghcr.io/cygnusb/wetterrekord und cygnusbn/wetterrekord.

Konfiguration

WETTERREKORD_LIVE_POLL_MINUTESAbfrageintervall live (15)
